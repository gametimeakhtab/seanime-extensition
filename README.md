# AnimeSalt Extension for Seanime

Online streaming provider extension for [Seanime](https://seanime.rahim.app/) that adds support for AnimeSalt (animesalt.ac).

## Supported Providers

| Provider | Status | Servers | Description |
|----------|--------|---------|-------------|
| **AnimeSalt** | ✅ Available | Default | Anime streaming provider for AnimeSalt |

## Extensions

**Installation:**
1. Open Seanime
2. Go to Extensions settings
3. Add this manifest URL:
   ```
   https://raw.githubusercontent.com/gametimeakhtab/seanime-extensition.json
   ```

## Requirements

- [Seanime](https://seanime.rahim.app/) application
